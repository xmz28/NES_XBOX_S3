# Nofrendo core

This directory contains the Nofrendo core from Espressif's
`esp32-nesemu` proof of concept. Nofrendo is distributed under GPL-2.0.
The board-specific SPI LCD, PlayStation controller and original ESP32 DAC
adapters are intentionally not included.
